## Research question
How does Mosswood's node-classification accuracy compare with Harrier-GCN's on the three graphs?

## Methods summary
Mosswood is a message-passing graph network with learned edge gating. Harrier-GCN is the main baseline and Kittiwake-Net a second baseline. Sorrel-Cite-XL is a larger, more recent crawl of the Sorrel-Cite citation graph; Tamarind-Social is a social-network graph.

## Experimental setup
Test accuracy is reported as the fraction of correctly classified test nodes (0–1; higher is better). All models use the standard public train/validation/test split of each graph; values are means over 5 seeds.
