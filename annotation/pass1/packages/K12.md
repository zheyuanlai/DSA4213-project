## Research question
How does Eddyline compare with Brenna-ODE in inference efficiency and forecast accuracy on Kestrel-Grid?

## Methods summary
Eddyline and Brenna-ODE share the same neural-ODE vector field (a 3-layer MLP) for 96-step-ahead electricity-load forecasting. Brenna-ODE integrates it with a fixed-step fourth-order Runge–Kutta solver (64 function evaluations, NFE, per forecast window). Eddyline replaces the fixed schedule with a learned step-size controller that needs far fewer evaluations; each Eddyline step additionally runs the controller network and an implicit correction solve, so one Eddyline step costs more than one RK4 stage. Sluice-TCN is a non-ODE convolutional forecaster included for reference.

## Experimental setup
Kestrel-Grid test split: 8,760 hourly forecast windows from 320 substations. Accuracy is mean absolute error (MAE, normalized load units; lower is better). We measured latency for all three models ourselves on one Halden H5 accelerator (fp32, batch size 256 windows, same software stack) as the median wall-clock time per batch over 50 timed batches after 10 warm-up batches. NFE is averaged over test windows.
