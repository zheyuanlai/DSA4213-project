## Research package (exactly what the systems received)

## Research question
Is Sablewing a more efficient sampler than Ordell-DDS for 256×256 face generation, and what does it cost in sample quality?

## Methods summary
Sablewing distils the Ordell-DDS denoiser into a student network that generates an image in 8 denoising steps (8 network function evaluations, NFE). The student is slightly wider than the teacher, so each of its evaluations costs somewhat more compute. Ordell-DDS is the 50-step teacher sampler; Ordell-DDS-10 runs the same sampler truncated to 10 steps.

## Experimental setup
Each sampler generates 30,000 images at 256×256 resolution for Halvern-Faces; FID is computed against the full Halvern-Faces reference set (lower is better). NFE counts denoiser evaluations per image, and TFLOPs per image are computed analytically from the network architecture and NFE. All models use fp16 weights. Wall-clock sampling time was measured by us for all three samplers on one Vantor V3 accelerator (fp16, batch size 64, same software stack), as the median of 10 timed runs after 3 warm-up runs, and is reported in seconds per batch of 64 images.
