## Research package (exactly what the systems received)

## Research question
Does Marten-GNN outperform Pinecrest-Conv across the four node-classification graphs?

## Methods summary
Marten-GNN is a graph neural network that mixes messages from multi-hop neighbourhoods with learned per-node hop weights. Pinecrest-Conv is a two-layer graph convolutional baseline with neighbourhood averaging. A feature-only MLP that ignores edges is included as a reference.

## Experimental setup
The benchmark comprises four node-classification graphs: Elmstead-Cite (citation network, 19k nodes), Harlow-Coauthor (co-authorship, 34k nodes), Brack-Social (social network, 51k nodes) and Tiller-Protein (protein interactions, 12k nodes). Each graph uses fixed train/validation/test node splits, and all models receive the same 40-trial tuning budget on the validation nodes. Metric: test accuracy (%), mean ± SD over 10 seeds.

  - comparison `exp1/cmp1`: Marten-GNN vs Pinecrest-Conv, test accuracy, per graph
  - comparison `exp1/cmp2`: Marten-GNN vs feature-only MLP, test accuracy, per graph
